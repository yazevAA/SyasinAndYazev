
# SEPTIKON ONLINE
# План разработки Frontend

## 1. Цель

Разработать клиентскую часть Septikon Online, которая будет взаимодействовать с Go Backend через HTTP API.

Работа выполняется поэтапно.

Главная задача первого этапа — получить работающее приложение, которое подключается к Backend, позволяет создавать игровые комнаты и отображает игровое состояние.

---

## Что можно делать прямо сейчас

Следующие задачи не требуют завершения всей игровой логики Backend:

1. Создание React + TypeScript приложения.
2. Настройка Vite.
3. Создание структуры компонентов.
4. Создание HTTP-клиента.
5. Создание главного меню.
6. Создание списка комнат.
7. Создание формы создания комнаты.
8. Создание экрана ожидания.
9. Подготовка визуального макета игрового поля.

Для остальных задач необходимо использовать актуальный API-контракт.

## Что пока нельзя делать без согласования

- Придумывать новые API-маршруты.
- Самостоятельно реализовывать серверные правила.
- Самостоятельно рассчитывать игровые результаты.
- Создавать фиктивные данные вместо реального состояния Backend.
- Считать неподтверждённые поля частью JSON-ответа.
- Реализовывать запуск ракеты через непроверенный маршрут.

Если для Frontend необходима новая функция, нужно согласовать её с Backend-разработчиком.

## Итоговая цель

Frontend должен представлять собой полноценный клиент игры Septikon Online.

Пользователь должен иметь возможность:

1. Открыть приложение.
2. Создать игровую комнату.
3. Подключить второго игрока.
4. Увидеть обе станции.
5. Получить информацию об игре.
6. Выполнять доступные игровые действия.
7. Видеть изменения состояния игры.
8. Играть через браузер.
